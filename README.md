# Health Planner

用很低的认知成本，换取持续的自我觉察。

随手说说睡眠、饮食、活动、指标或身体感受，Health Planner 会按时间线整理今日进度，结合目标给出有依据的建议，并在每周、每两周和每个月主动与你复盘。

## 使用

将本仓库作为 `health-planner` 技能目录安装到支持 Skill 的工具中。在 Codex 中可以发送：

```text
使用 $skill-installer 安装 https://github.com/rigenmu/health-planner
```

然后自然开始：

```text
使用 $health-planner。我想控制体重，先记录睡眠、晨重、饮食和活动。
```

已安装过的用户更新到仓库最新版本后，重新读取 `$health-planner`，保留原档案、周期起点和已接受计划即可继续。

## 轻量内核，个人内容按需沉淀

2.1.0 不附带运行脚本、Python 依赖、测试工程或固定 JSON 模板。入口包含日常记录和反馈规则，三份说明只在需要时读取：

- [健康建议](references/health-guidance.md)：循证建议、计划和症状跟进。
- [周期复盘](references/reviews.md)：周／双周／月度分析、对话交付与讨论。
- [个人档案](references/personal-records.md)：按需生成私人 Markdown、历史导入及接续。

普通聊天就能开始。希望长期保存时，助手可在你同意的文件夹内，从一份私人 Markdown 起步，沉淀你的偏好、计划和跟进状态；记录变多再按需拆分。已有档案继续使用，无需为这次精简重做迁移。

日常直接用聊天时间线，新内容加粗，末尾一段自然反馈。需要完整日结或复盘时再展开，不生成新的 HTML 卡片。主动复盘会在互动和归档时检查并发起；关闭对话后的定时提醒需要另行配置支持的自动化。

可提供健康管理支持，不能确诊或自行调整处方药。重要建议需要核查适用依据；数据不够时说明不确定性。个人资料留在私人位置，不随本仓库传播。当前不包含跨设备存储或后台服务。
